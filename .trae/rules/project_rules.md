# 项目规则（开工必读）

> 本文件是 Westworld（mc-next）的最高优先级项目规范。
> 每次开始任何开发、改版、修 UI 之前，先读本文件，再读 `AGENTS.md`，最后再动代码。
> 新增或调整 UI 时，逐条对照本文件自检；规范有变化时，先改本文件，再改代码。

---

## 一、视觉与配色

1. **控制配色**
   - 底色与文字使用中性色（黑、白、灰、米白），不堆叠高饱和色。
   - 品牌主色为**绿色**：主操作按钮、当前导航、选中 Tab 使用绿色渐变（`#10b981 → #059669`），文字用白色。
   - 除品牌绿渐变外不使用装饰性渐变，不使用发光（彩色外发光、neon、glow 一律不要）。
2. **统一设计变量**
   - 间距、圆角只用固定档位，不写随手数字。
   - 组内紧凑，组间留白。
   - 卡片、分组必须保留圆角（8/12/16/24），不要出现直角面板。
3. **对齐**
   - 同一类元素的**左边缘对齐**；标题、名称、正文同一条基线。
4. **删装饰**
   - 删掉多余装饰；
   - 全站只用**一套线性图标**；
   - 删除表情符号、感叹号和装饰性徽章。

### 固定档位（项目默认）

| 类型 | 档位 |
|---|---|
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px |
| 圆角 | 8 / 12 / 16 / 24 px |
| 边框 | 1px，中性色低对比 |
| 动效时长 | 入场 180–240ms，退场 120–160ms，悬停 120–150ms |

## 二、布局与排版

1. **设置项排版**
   - 名称放左边，控件放右边；
   - 一项设置占一行；
   - 用户视线路径：左边找名称，右边看选项。
2. **去掉外框**
   - 去掉最外面那层框，页面不再套一层卡片；
   - 内容直接落在页面背景上，用间距和分组表达层级。
3. **分组**
   - 每个组必须有标题；
   - 组间多留白，组内少留白；
   - **删除类操作单独放**，不和普通设置混在一起。

---

## 三、表单（重要例外）

左右排只适合小控件和单独保存的设置。顺序填写的表单必须上下排。

| 场景 | 排布 |
|---|---|
| 开关、下拉、单个数值、独立保存的设置 | 名称左、控件右 |
| 需要按顺序填写的表单 | 名称在上、控件在下 |
| 错误提示 | 紧贴控件下方，占满整行 |

原因：左右排会挤窄输入框，错误提示也被挤在半列里。名称上置更清楚。

## 四、动效（高性能、低端设备友好）

原则：**能打断、轻退场、柔和切换、入场缓出，按压有回弹。**

0. **不做阻塞式加载层**
   - 不使用全屏加载遮罩拦截站内跳转；页面切换只允许非阻塞的骨架或局部占位。
1. **优先过渡动画**
   - 用 `transition`，不用会从头重来的关键帧动画；
   - 过渡可以就地转向，用户随时能打断。
2. **退场要轻**
   - 不要一路飞出屏幕；
   - 移出一小段（约 4–8px）再淡出，可加轻微模糊。
3. **图标切换**
   - 交叉淡化 + 轻微缩放 + 轻微模糊，不要生硬替换。
4. **入场用缓出**
   - 起步快、收尾轻，使用 `ease-out` 一类曲线；
   - 避免匀速，匀速看起来像机器。
   - 按钮按压使用 spring（`stiffness` 400–450、`damping` 20–24），悬停轻微放大，做出 Q 弹回馈。
5. **性能约束**
   - 只对 `transform`、`opacity`、`filter` 做动画；
   - 不动画 `width` / `height` / `top` / `left`；
   - 尊重 `prefers-reduced-motion: reduce`，关闭位移与缩放。

---

## 五、侧边栏

内容不变，只理顺间距：

- 圆角跟旁边的面板一致，不贴边；
- 标题和菜单对齐；
- 图标比文字小一点；
- 图标与文字之间拉开距离；
- 每行上下留空，保持呼吸感；
- 同一组靠近，不同组拉开，一眼能分清分组。

---

## 六、细节清单

1. **等宽数字**：数值使用 `font-variant-numeric: tabular-nums`，变化时不左右跳动。
2. **同心圆角**：外层圆角 = 内层圆角 + 内边距。
3. **错峰入场**：不要整块内容一起带入，拆成几部分依次错开（每级约 40–60ms）。
4. **标题换行**：平衡换行，避免最后一行只剩一个词（`text-wrap: balance`）。
5. **阴影代替边框**：用柔和的多层阴影，换背景也能自然融入。
