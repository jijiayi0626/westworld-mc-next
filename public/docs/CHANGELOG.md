## v2.5.0（2026-02-07）

### 新增
- **论坛模块**：公告与聊天室整合进用户中心「论坛」页（Tab 切换）；聊天消息迁移至独立 D1 数据库 `westworld-forum`，支持后续扩展（板块、回复等）
- **论坛设置**：后台可控制论坛内公告 / 聊天 Tab 的显示开关
- **MOTD 查询 API**：接入 MineBBS MOTD 公开接口（`/api/monitor/motd`），帮助页提供在线查询卡片，监控后台可快速查询；源站可在网站设置键值 `motd_api_base` 覆盖
- **商店经济插件对接**：通过 RCON 执行余额查询 / 扣款指令（指令模板可配，`{player}` `{amount}` 占位符）；启用后用户下单可选「游戏币支付」，余额校验 → 自动扣款 → 订单直接进入「已支付」；用户端显示绑定游戏 ID 与实时余额；后台商城新增「经济插件」配置与连通性测试
- **图片管理增强**：图片支持后台重命名（存储于 `image_meta` 表）、点击查看大图预览
- **多模板 + 深浅主题**：侧栏「外观设置」支持「现代 / 经典」两套模板与「浅色 / 深色 / 跟随系统」模式切换，本地记忆、首屏内联脚本防闪烁
- **后台「关于本站」重做**：新增 README 与更新日志在线查看（数据来自 `public/docs/` 静态副本）

### 修复
- 聊天室发送文字 / 图片 HTTP 500：查询了不存在的 `users.avatar_url` 列（正确列名为 `avatar`）
- 表情图标统一替换为内联 SVG（规则页 / AI 助手 / 聊天附件 / 后台警告），不再依赖 emoji
- 多端适配：小屏表格横向滚动兜底、聊天室高度 dvh 自适应、气泡宽度优化

### 变更
- 后台「网站设置」页重做：按「基础配置 / 论坛与聊天 / 三方集成」三个分区重组，键值设置支持搜索
- 顶部导航合并：12 项收敛为 5 项 +「更多」下拉；窄屏 / 移动端自动收纳
- 聊天室入口移入论坛；GitHub README 全面重写
