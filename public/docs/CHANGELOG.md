版本规则：版本号统一为四位 `X.Y.Z.N`，按更新内容定级。日常修复与小功能递增第四位（如 `0.9.10.0` → `0.9.10.1`）；成体系的功能更新递增第三位（如 `0.9.9.0` → `0.9.10.0`）；仅重大改版时才进位第二位。首次推送记为 `v0.0.1.0`。

## v0.9.8.0（2026-11-10）

主题改为真正的「主题包」架构。

### 变更
- **主题包独立目录**：每套主题是 `src/themes/<key>/` 下的完整前端包，自带 `Layout.tsx`（导航 / 页脚 / 页面骨架）、`Home.tsx`、`theme.css` 与 `theme.json`，不再是同一套页面换 CSS
- **构建时挑选主题**：`npm run build` 会先执行主题构建脚本，读取 `THEME_SLOTS` 只打包指定主题，未选中的主题不会进入产物
- **运行时按主题挂载**：后台切换后只挂载该主题的 Layout、Home 与独立样式文件，另一套结构和 CSS 都不会出现在页面上
- **主题样式独立加载**：主题样式从全局 `<link>` 改为按需加载 `/themes/<key>/theme.css`，首屏由内联脚本按缓存提前插入，避免闪烁
- **后台只显示已构建主题**：外观页的模板列表直接来自构建产物，新增主题无需改后台代码

### 新增
- **`npm run themes`**：扫描主题包并生成注册表与静态资源
- **`npm run theme:add -- <主题包.zip|目录>`**：把主题压缩包安装到 `src/themes/<id>/`，校验通过后自动重新构建
- **主题包格式**：`theme.json`（id / name / description / version / swatch / css）+ `Layout.tsx` + `Home.tsx` + 可选 `theme.css`

- **账号绑定**：安全中心新增 INU 绑定卡片，支持绑定 / 解绑，展示 INU ID、昵称与会员等级；已登录用户也可把 INU 账号绑定到现有本地账号

- **退出撤销**：INU access_token 加密存入 `inu_accounts`，退出登录或解绑时调用 `/oauth/revoke` 撤销，成功后清除本地令牌

### 安全
- `state` 与 PKCE verifier 存放在 AES-GCM 加密的 HttpOnly Cookie 中，10 分钟过期、回调一次性消费；`state` 使用恒定时间比较

- 发起授权与回调均按 IP 限流；回调失败只返回错误码，不把 `code`、token 或原始错误抛到页面
- 绑定接口校验当前会话与用户状态；INU 账号已绑定其他本地账号时返回冲突提示

### 数据库迁移
- 新增 `inu_accounts` 表，已写入 `schema.sql` 与 `scripts/migrate-inu-oauth.sql`

### 配置
- 新增 `INU_ORIGIN`、`INU_CLIENT_ID`、`INU_CLIENT_SECRET`、`INU_REDIRECT_URI`、`INU_SCOPES`；回调地址为 `https://westworld.inumc.dpdns.org/api/inu/callback`

## v0.6.1.0（2026-10-31）

安全加固版本。对全部后端路由做了一轮纵深排查，重点修补支付、OAuth、RCON 与限流链路。

### 安全加固
- **AI 每日额度原子化**：额度检查与计数合并为一条 `INSERT ... ON CONFLICT ... WHERE count < ?`，并发请求无法再绕过上限
- **支付回调校验**：Creem Webhook 改为校验 `creem-signature`（HMAC-SHA256 原始报文），并校验事件类型、订单号、币种与实付金额（分），只有金额匹配才发货；发货更新限定 `pending` 状态，重复回调不会重复发货
- **Creem 下单接口修正**：改为官方 `POST /v1/checkouts`，字段使用 `product_id` / `units` / `request_id` / `success_url` / `metadata`，支持通过 `CREEM_API_BASE` 切换测试环境
- **OAuth 一次性 state + PKCE**：微软绑定改为 15 分钟一次性 `jti`（原子 `DELETE ... RETURNING` 消费），并保存加密的 PKCE verifier，回调携带 `code_verifier`
- **恒定时间比较**：易支付签名、密码重置码、Creem 回退密钥改用 `timingSafeEqual`，避免时序侧信道
- **客户端 IP 防伪造**：`cf-connecting-ip` 优先；仅在显式设置 `TRUST_PROXY=true` 时才读取 `X-Forwarded-For`，默认 `false`
- **论坛发帖/回复限流**：发帖单账号 10 分钟 6 帖、单 IP 20 帖；回复单账号 30 条、单 IP 60 条
- **后台配置防串改**：`/api/admin/settings` 拒绝直接写入 `ai_config`、`ai_providers`、`ms_oauth_config`、`rainyun_config`、`pay_epay`、`rcon_whitelist`，必须走对应专用页面
- **Markdown 协议白名单**：链接与图片仅允许 `http(s)`、`mailto`、站内路径和锚点，阻断 `javascript:` / `data:` 等伪协议
- **RCON 密码加密**：旧明文密码在读取时自动升级为 AES-GCM `enc:v1:` 密文；余额查询等 RCON 错误不再把原始报文返回给用户，仅写入操作日志
- **游戏币下单串行化**：新增 `shop_order_locks` 用户级锁（60 秒 TTL），同一用户并发下单串行执行，避免余额重复扣减
- **注册并发兜底**：并发注册触发 UNIQUE 约束时返回 409，而不是 500

### 数据库迁移
- 新增 `oauth_states`（OAuth 一次性 state）与 `shop_order_locks`（下单锁）两张表，已写入 `schema.sql`，代码首次使用时也会自动建表
