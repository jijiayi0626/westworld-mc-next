# 更新日志（CHANGELOG）

## v2.6.0（2026-10-25）

### 新增
- **商城库存与自动发货**：商品支持库存（-1 不限量，下单占用、取消/超时归还）与 RCON 发货指令模板（`{player}` `{qty}` `{order_no}` `{product}` `{amount}`）；支付成功后自动发货，失败进入重试队列（每 5 分钟补发，最多 30 次），后台可查看发货状态 / 重试 / 手动发货；未支付订单 30 分钟后自动取消
- **订单体验**：用户订单页新增「全部 / 待支付 / 待发货 / 已完成 / 已取消」状态筛选，展示自动发货进度；商品卡展示库存与售罄状态
- **图库孤儿图片检测**：跨站点内容、公告、头像、聊天、商品描述、工单附件、入服申请、留言、AI 对话、论坛扫描图片引用，标记「未使用」并支持一键清理（1 小时内新图自动跳过）
- **工单附件**：用户与管理员均可上传图片 / PDF / ZIP（单文件 10MB，最多 5 个），随回复展示与下载
- **邮件事件通知**：后台可配置通知收件人与「新工单 / 入服申请 / 新订单 / 联系留言」开关；未填收件人时默认发送给管理员账号邮箱
- **后台新建用户**：可直接创建普通用户或管理员，校验用户名 / 邮箱 / 密码强度与重复
- **用户资料扩展**：支持绑定 QQ / Discord；用户中心新增「新人任务」进度卡（头像、签名、游戏名、QQ、Discord、入服申请）
- **安全与稳定性**：密码策略统一为 8-64 位且包含字母和数字；API 全局错误统一返回 JSON；登录过期（401）自动跳转登录页

### 数据库迁移
- 新增 `scripts/migrate-user-socials.sql`、`scripts/migrate-shop-delivery.sql`、`scripts/migrate-ticket-attachments.sql`，已有部署需按需执行

## v2.5.0（2026-02-07）

### 新增
- **论坛模块**：公告与聊天室整合进用户中心「论坛」页（Tab 切换）；聊天消息迁移至独立 D1 数据库 `westworld-forum`，支持后续扩展（板块、回复等）
- **论坛设置**：后台可控制论坛内公告 / 聊天 Tab 的显示开关
- **MOTD 查询 API**：接入 MineBBS MOTD 公开接口（`/api/monitor/motd`），帮助页提供在线查询卡片，监控后台可快速查询；源站可在网站设置键值 `motd_api_base` 覆盖
- **商店经济插件对接**：支持通过 RCON 执行余额查询 / 扣款指令（指令模板可配，`{player}` `{amount}` 占位符），提供连通性测试
- **图片管理增强**：图片支持后台重命名（存储于 `image_meta` 表）、点击查看大图预览
- **多模板 + 深浅主题**：前台外观设置支持「现代 / 默认」两套模板与「深色 / 浅色」模式切换，本地记忆、刷新无闪烁
- **后台「关于本站」重做**：新增 README 与更新日志在线查看（数据来自 `public/docs/` 静态副本）

### 修复
- 聊天室发送文字 / 图片 HTTP 500：查询了不存在的 `users.avatar_url` 列（正确列名为 `avatar`）
- 表情图标统一替换为内联 SVG（规则页 / AI 助手 / 聊天附件 / 后台警告），不再依赖 emoji
- 多端适配：小屏表格横向滚动兜底、聊天室高度 dvh 自适应、气泡宽度优化

### 变更
- 后台「网站设置」页重做：按「站点基础 / 三方接口 / 聊天室 / 商店经济 / 高级」分区重组
- 顶部导航合并：12 项收敛为 5 项 +「更多」下拉；窄屏 / 移动端自动收纳
- 聊天室入口移入论坛；GitHub README 全面重写
